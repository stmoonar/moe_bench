## 2. 双峰"漂移"现象与环境干扰假说

三轮观察拼起来：

- 第六轮：T=1024 双峰（med 10020/min 4210），其余全稳；
- 第七轮：T=1024 完全恢复（4199 稳定），**双峰漂到 NE=256/RB64**
  （med 6330/min 4914，min 与上轮稳定值一致）；且 **serial_t256 也出现
  离群**（mean 1826 vs med 1677）——serial 是纯 NCCL+triton，与我们的
  kernel 无共同路径。

**假说：机器级间歇干扰**（共享 16 卡机上其它租户的 PCIe/host 流量或时钟
波动），不是我们的协议 bug。证据链：①双峰随轮次在不同配置间游走，无固定
复现条件；②serial 同样中招；③每个双峰档位的 min 都恰好等于稳定轮次的
值（快模式 = 无干扰模式）。

**取证手段（本轮已加，下轮裁决）**：①每步结束记录全卡
clocks.sm/温度/利用率/显存（clocks_per_step.csv，可对出干扰时间窗）；
②波动档位（t1024、ne256_rb64）同 session 重复跑两次——内因应两次都双峰，
外因则随机。**报数纪律：波动档位看 min 与重复一致性，med 用于稳定档。**
